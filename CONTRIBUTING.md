# Contributing

Issues and pull requests are welcome.

```bash
git clone https://github.com/nikhilcherry/hoist && cd hoist
pip install -e ".[dev]"
pytest -q
```

- **No runtime dependencies.** hoist is standard-library only, on purpose. A
  change that adds one will need a very good reason.
- Python 3.9 must keep working (CI runs 3.9, 3.11 and 3.13).
- Bug fixes come with a test that fails without the fix.
- Anything that touches the tunnel config, systemd units or deploy path should
  say how you tried it for real, not only in unit tests.
- Screenshots in `docs/` are generated by `scripts/make_docs_images.sh`; don't
  hand-edit them.
